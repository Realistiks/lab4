📚 Выполненные задания
Часть 1. Лабораторные работы
Чётность и знак: проверка через % 2, % 3 и цепочку if/elif/else, тернарный оператор для компактного вывода.
Максимум из трёх: последовательные сравнения без max().
Возраст: цепочка elif от меньшего к большему (0–12, 13–17, 18–64, 65+).
Квадратное уравнение: D = b² - 4ac; два корня / один корень / нет корней; отдельно обработан случай a = 0.
Калькулятор: оператор множественного выбора match (аналог switch из C++), обработка деления на ноль.
Високосный год: (год % 4 == 0 and год % 100 != 0) or год % 400 == 0. Проверено: 2024 — да, 1900 — нет, 2000 — да.
Треугольник: проверка существования (a+b>c, a+c>b, b+c>a), затем тип: равносторонний / равнобедренный / разносторонний.
Дни в месяце (вариант 6): февраль — 28 или 29 дней в зависимости от високосности, апрель/июнь/сентябрь/ноябрь — 30, остальные — 31; проверка корректности номера месяца.
Часть 2. Самостоятельная работа
Угадай число: компьютер загадывает 1–100, подсказки «Больше/Меньше», счётчик попыток, защита от нечислового ввода через try/except и continue.
Системы счисления: перевод в 2-ю, 8-ю и 16-ю через bin(), oct(), hex() со срезами префиксов; для отрицательных чисел знак добавляется вручную.
ИМТ с категорией: ИМТ = вес / рост², категории: <18.5, <25, <30, ≥30; авто-перевод сантиметров в метры.
Координатная четверть: начало координат, оси X/Y или одна из четырёх четвертей.
⚙️ Особенности реализации
Везде использованы конструкции ветвления: if / elif / else, тернарный оператор, match.
Обработаны краевые случаи: деление на ноль, a = 0 в уравнении, некорректный месяц, отрицательный возраст и вес, нечисловой ввод.
Код простой и читаемый, с комментариями в ключевых местах.
В репозитории 3 коммита (задания 1–4, задания 5–8, самостоятельная работа).
